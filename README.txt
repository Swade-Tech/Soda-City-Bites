SODA CITY BITES - GITHUB PAGES READY WEBSITE

Author: Sean Wade

Files included:
- index.html
- southern-food.html
- international-food.html
- desserts-drinks.html
- recommend.html
- styles.css
- images/ folder with the provided food images

The website uses:
- External CSS: styles.css
- Internal CSS: the <style> block in index.html
- Inline CSS: the style attribute on the Home page heading

Each HTML page includes an author comment in the <head> section.

To test locally:
1. Open this folder in Visual Studio Code.
2. Open index.html.
3. Use Live Server if installed.
4. Click every navigation link to make sure all five pages work.

GitHub Pages:
1. Create a public GitHub repository named soda-city-bites.
2. Upload the website files and the entire images folder. Do not upload only the ZIP file.
3. Go to Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and /(root), then Save.
6. Wait for GitHub Pages to finish publishing.
7. Open the Pages URL and test all five pages.

Submit:
- Your GitHub Pages website URL
- Your GitHub repository URL
